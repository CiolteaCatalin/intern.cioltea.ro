# Cioltea Hub V23.2.0 - Pregătire cache fotografii

În Setări > Cache & performanță: Pregătește preview-urile, progres și Oprește. Se parcurg recursiv folderele Digi Storage, maximum 2 thumbnail-uri simultan. Fișierele deja pregătite sunt sărite. Cache-ul local rămâne până la 180 zile de la ultima folosire. Procesul rulează numai cât pagina Setări este deschisă; dacă se întrerupe, reia fără să descarce imaginile deja salvate. Nu descarcă originalele în cache, doar thumbnail-uri JPEG. Nu șterge storage/ și nu suprascrie security/config.php.
